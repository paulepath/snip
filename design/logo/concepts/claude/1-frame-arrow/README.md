# Frame-arrow

A refined evolution of today's icon: two white crop corners frame the selected region, and the editor's red arrow
is the drag that drew it, running corner to corner so that its filled, right-angled head becomes the region's third
corner. It says the whole of Snip in one gesture (drag a region, then mark it up), keeps the icon users already know,
and still reads at 16 px because it is only three heavy shapes on a tile. The wordmark is drawn on the same round
monoline stroke, with the dot of the "i" in the arrow's red.
