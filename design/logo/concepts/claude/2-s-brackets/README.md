# 2 · S-brackets

The S is two crop corners from Snip's own selection frame, a top-left corner and a bottom-right corner turned 180°
about the centre, so the mark is at once the letter and the drag-a-region rectangle. The short red bar between them
(the editor's arrow red) is the snip itself: the cut that joins the two corners into one letter. It is drawn on a
4-unit grid so that at 16 px every bar is a whole 3 px stroke with 2 px gaps and stays sharp in the tray; the
wordmark is drawn as 8-unit monoline paths with square ends and mitred corners, the same blocky geometry as the
brackets, with a red square dot on the i.
