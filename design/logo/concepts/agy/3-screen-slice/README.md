# Concept 3: Screen Slice

A captured screen frame divided by a surgical 45-degree diagonal shear cut, peeling back to reveal Snip's marquee editor markup layer beneath: the green numbered step disc `①` and red callout arrow.

Unlike generic screenshot utilities, Snip's value is in its editor—especially its arrows and numbered steps. The sliced composition physically represents the word "Snip" while celebrating its workflow in Total Git and Panehouse's distinctive multi-layered palette.
