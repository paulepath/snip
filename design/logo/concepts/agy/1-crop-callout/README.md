# Concept 1: Crop Callout

A refinement of Snip's core DNA: four precision viewfinder crop brackets framing an active selection region, with Snip's signature coral red annotation arrow locking directly onto target.

It captures the immediate feeling of hitting Print Screen, dragging a region, and annotating a bug or detail. The heavy 5.5px strokes and high-contrast red dart remain sharp and instantly recognizable down to 16px in the Windows system tray.
